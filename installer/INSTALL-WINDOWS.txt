Milso Launcher - Windows sub-app
==============================

One-click install:
  1. Extract milso-launcher-<version>-win.zip anywhere.
  2. Double-click setup-win.bat at the top level
     (installer\setup-win.bat works too; or: powershell setup-win.ps1).
  3. Launch from Start Menu -> Milso Launcher, or run-win.bat.

It installs Python 3.11+ via winget when missing, creates .venv,
installs PySide6, and adds a Start Menu shortcut. Nothing needs admin
except the optional winget Python install.

Your games, Saves/, backups/, artwork and settings are kept on upgrade:
re-run setup-win.bat -Target <same folder> -Yes.

Linux remains the main version (.run installer). Both check the same
GitHub Releases; each downloads its own asset (.run vs -win.zip).
